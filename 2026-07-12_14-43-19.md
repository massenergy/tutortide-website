# Implementation Plan — Tutortide Marketing Site Redesign & Restructure

**Date:** 2026-07-12
**Status:** DRAFT — awaiting review & approval (no source files will be changed until approved)

---

## 1. Goal

Rebuild `tutortide.online` as a clean, multi-page marketing hub in the visual language of
[conductorai.com/platform](https://www.conductorai.com/platform), and restructure the site so
**marketing lives on paths** and **apps live on subdomains** (per the Website Format doc).

### Architecture (from the format doc)

| Product | Marketing page (THIS repo builds) | App subdomain (Cloudflare DNS — out of scope) | Existing content source |
|---|---|---|---|
| — (company) | `/`, `/about`, `/products`, `/contact` | — | current `public/index.html` |
| Jinjing | `/jinjing` | `jinjing.tutortide.online` | jinjing-landing-page.web.app, aistudentcompanion.tutortide.online |
| Nyokavi | `/nyokavi` | `nyokavi.tutortide.online` | massenergy.github.io/nyokavi |
| Waterpro | `/waterpro` | `waterpro.tutortide.online` | **no site yet — PRD pending from user** |
| Tundamoto | `/tundamoto` | `tundamoto.tutortide.online` | tundamoto-website.web.app |

Each product page contains: features, screenshots, pricing, testimonials, FAQs, videos, sign up,
and a **Launch App / Login** CTA pointing at its subdomain.
**Waterpro is special:** two login destinations — MOWP Admins (`waterpro-39519.web.app`) and MOWP
Members (`waterpro-39519-admin.web.app`) — so its page needs two CTAs.

### Locked decisions

1. **Hosting:** root stays on **Firebase Hosting** (project `tutortide-5a652`). Cloudflare only does
   DNS for the app subdomains (handled separately by the user).
2. **Build tool:** **Astro** (static output, real shared components) → builds to `dist/` → Firebase serves `dist/`.
3. **Content:** reuse copy/screenshots from existing live sites + realistic placeholders with `TODO`
   markers for gaps. Waterpro content comes from a forthcoming PRD.

### Out of scope

- Cloudflare subdomain DNS records (`*.tutortide.online`) — user does this.
- Any change to the product **applications** themselves. We only link to them.

### Assumptions (please confirm during review)

- **A1.** Astro is acceptable over the current single-file Tailwind CDN approach. It replaces
  `public/index.html` as the source of truth; the old file gets archived, not served.
- **A2.** `tutortide.online` currently resolves to Firebase Hosting for `tutortide-5a652`. If the
  domain currently points elsewhere, the final DNS cutover is a separate step.
- **A3.** Git is connected (`main`, remote `origin` = `github.com/massenergy/tutortide-w`), nothing
  committed yet. **Workflow (per reviewer):** baseline-commit `main`, then do the redesign in a
  separate **git worktree** on a feature branch, and **merge back to `main`** when done.
- **A4.** Contact + "sign up" are **mail-to links to `info@tutortide.online`** for now (no form
  backend). Product sign-up CTAs route to the app subdomain.
- **A5.** No `worker.py` / GitHub Actions CI exists here (unlike the plan skill's default). Deploy is
  `astro build` + `firebase deploy`. See Phase 9 for the adapted final phase.

## 2. Design system (Conductor-inspired) — reference spec

Distilled from `conductorai.com/platform`:

- **Canvas:** near-white `#F6F6F4` / white sections; hairline `1px` neutral borders forming a modular grid.
- **Ink:** near-black `#111111` text.
- **Accent:** a single royal blue `#1A44FF` (approx) for CTAs, links, stat numbers, active states. Used sparingly.
- **Type (match Conductor — reviewer chose free faces that match the reference):**
  - *Display/headings:* **Space Grotesk** (bold), the closest free grotesque to Conductor's headline face. Large, tight tracking.
  - *Micro-labels:* **JetBrains Mono** (uppercase) for eyebrows, section numbers, stat captions ("PROCESSING //", "01 HOME").
  - *Body:* **Inter** (already loaded today — keep for continuity).
  - Self-hosted via `@fontsource` for perf/SEO. (Swap trivially if a licensed brand font is preferred.)
- **Motifs:**
  - Corner-tick "registration mark" brackets on grid cells (the ⌐ ⌐ corners).
  - Dotted-grid background texture on select sections.
  - Big stat numbers ("10x", "932", "98%") with mono captions.
  - Full-width solid-blue CTA bars and blue section blocks.
  - Numbered footer nav (`01 HOME`, `02 PLATFORM`, …).
- **Motion:** restrained — subtle fade/rise on scroll, animated progress bars. No heavy parallax.

These become Tailwind theme tokens + a small set of reusable Astro components (see Phase 2).

## 5. Phase 9 — Commit & Deploy (adapted to this project)

> **Deviation from the plan-skill default (documented):** this repo has **no `worker.py` and no
> GitHub Actions CI**. Git IS connected. The mandatory commit/deploy steps are adapted to this
> project's real toolchain: commit on the feature branch → merge to `main` → Astro build → Firebase
> Hosting deploy. Frontend-only deploy — no backend/Cloud Run smoke test applies.

Steps (run from the redesign worktree, then main):
1. Commit the work on the feature branch:
   `git add -A && git commit -m "Redesign tutortide.online: Conductor-style multi-page marketing hub"`
   then `git push -u origin feature/marketing-redesign`.
2. **Merge to main** (per reviewer): from the main tree,
   `git checkout main && git pull && git merge --no-ff feature/marketing-redesign && git push origin main`.
3. Build: `npm run build` (must exit 0, `dist/` populated).
4. Deploy: `firebase deploy --only hosting` (project `tutortide-5a652`).
5. **Verify deploy** by browsing the live domain (no CI to check):
   - `/browse` each of the 8 routes on `https://tutortide.online/…` → all 200.
   - Product CTAs resolve to the correct subdomains (Waterpro → both member/admin URLs).
   - `curl -I https://tutortide.online/jinjing` → `200` with clean URL.
6. Confirm the old SPA behavior is gone (deep links like `/waterpro` no longer fall back to the home SPA shell).
7. Clean up: `git worktree remove ../tutortide-redesign` (branch already merged).

**Leaves:** redesigned site live on Firebase Hosting; `dist/` is the deployed artifact; `main` clean
with the feature branch merged; redesign worktree removed.
