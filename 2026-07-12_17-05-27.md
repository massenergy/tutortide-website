**Date:** 2026-07-12
**Status:** DONE — implemented, merged, deployed
**Follow-on to:** the completed redesign (`2026-07-12_14-43-19.md`), already deployed to Firebase.

## 1. Goal

Make the Tutortide site feel alive with **ambient, Conductor-style motion** — filling bars, dots
traveling along dotted lines between elements, and dots orbiting each card's perimeter — while
staying **subtle** and **fully respecting `prefers-reduced-motion`**.

### Locked decisions (from review)

1. **Character = ambient & subtle.** Slow continuous loops always running quietly, ~6–10s cycles,
   ease-in-out. Never distracting.
2. **Scope = home + product hero/stats.** Full motion on the home page. On product pages, only the
   **hero readout bars** and the **stat band** animate; deep content (product capability grids,
   feature deep-dives, FAQ) stays calm/static.
3. **Connectors (traveling dot on a dotted line)** on: between the four **product cards**, between
   the **stat numbers**, between **capability cards** (home only), plus **card-perimeter dots**.
4. **Fill bars = continuous processing loop** — gentle fill/ebb matching "PROCESSING // IMPACT".

### The perimeter effect (user's spec)

On each product card a small dot travels **L→R along the top edge** and **R→L along the bottom
edge**. Each card is **phase-offset** ("different stages of the journey") and **alternates
direction/speed** on the next card.

### Non-negotiable constraints

- **CSS + inline SVG only.** No JS animation loops. Animate **only `transform`/`opacity`** (GPU-friendly).
- **`prefers-reduced-motion: reduce` freezes to a clean static state:** bars show at their value,
  traveling dots hidden, connectors become plain dotted lines. No motion at all.
- **Lighthouse performance stays ≥ 90.** Negligible JS added; no layout thrash.
- **Connectors are desktop-only** horizontal overlays, hidden when cards stack on mobile. **Perimeter
  dots remain on mobile** (self-contained per card).

### Assumptions (confirm in review)

- **A1.** Work reuses the existing worktree `../tutortide-redesign`, on a **new branch
  `feature/motion` off `main`** (worktree currently sits on the merged `feature/marketing-redesign`;
  Phase 0 rebases it to a fresh branch off `main`).
- **A2.** The animated `Meter` replaces the unicode `▓` block meters in the hero readout panels
  (home + all four product pages) — same labels, real animated bars.
- **A3.** No `worker.py`/CI here; deploy is `npm run build` + `firebase deploy` (documented deviation).
- **A4.** Numbers stay static (no count-up) — that's a scroll-trigger effect and we chose ambient.
  Motion between numbers is the connector dot only.

## 2. Motion primitives (design reference)

All keyframes live in `src/styles/global.css`, gated behind
`@media (prefers-reduced-motion: no-preference)`, with a `reduce` block forcing static.

| Name | What it does | Applied to | Cycle |
|---|---|---|---|
| `meter-breathe` | fill width eases between ~45% and ~80% | animated bars in readouts | 7–9s |
| `travel-x` | element moves `translateX(0 → 100%)` along a track | perimeter top dot, connector dots | 8–10s |
| `travel-x-rev` | `translateX(100% → 0)` | perimeter bottom dot | 8–10s |
| `dash-drift` | `background-position` shift on a dashed line (subtle "flow") | connector lines, dotted grid | 10s |
| `dot-pulse` | tiny `opacity`/`scale` breathing on a node dot | connector endpoints | 4s |

**Phase offset / alternation** is data-driven via a CSS custom property `--phase` (a negative
`animation-delay`) set per card index, so each card starts mid-journey and neighbors differ. Even/odd
cards get slightly different durations (`--speed`) and swapped directions.

## 5. Phase 6 — Commit & Deploy (adapted to this project)

> **Documented deviation:** no `worker.py` / GitHub Actions CI here. Deploy = build + Firebase.

1. Commit on the branch: `git add -A && git commit -m "Ambient motion: filling bars, perimeter dots, traveling connectors"`; `git push -u origin feature/motion`.
2. Merge to main: from the main tree, `git checkout main && git pull && git merge --no-ff feature/motion && git push origin main`.
3. Build: `npm run build` (exit 0).
4. Deploy: `firebase deploy --only hosting --project tutortide-5a652`.
5. **Verify live** via `/browse` on `https://tutortide-5a652.web.app`:
   - Home bars/dots/connectors animate; a product page hero animates.
   - All 8 routes still 200 (`curl -sI`).
   - Reduced-motion still static on the live build.
6. Leave `main` clean with the branch merged. (Worktree kept for further follow-ups unless you want it removed.)
